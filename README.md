## 搬瓦工 PayPal 付款会自动续费吗？

不会直接从 PayPal 自动扣款。

官方知识库的表述很明确：搬瓦工不保存客户的信用卡或 PayPal 付款信息，因此所有付款都必须由用户主动发起。

但这不代表服务一定会无限期保留。续费机制仍然存在：

- 如果续费状态为开启，系统会生成下一周期账单；
- 如果账户余额足够，系统可以使用账户余额支付；
- 如果没有足够余额，用户需要在规定时间内手动付款；
- 长时间不付款，服务可能被暂停或自动取消；
- 如果续费状态关闭，服务可能在当前周期结束时终止。

因此，使用 PayPal 购买后，最好在客户端区域查看 Renewal 状态。不要把“不会自动扣 PayPal”误解成“永远不会产生续费账单”。

搬瓦工允许用户修改未来的计费周期，但已经生成或已经支付的账单通常不能追溯修改。

## 退款和 PayPal 争议需要注意什么？

搬瓦工公开的退款政策不是“付款后随时退款”。官方条款列出了多个条件，包括：

- 申请退款的服务必须是新订单，而不是续费；
- 新订单通常需要在下单后 30 天内；
- 账户状态正常，没有违反服务条款；
- 没有正在进行中的争议或拒付；
- VPS 月流量使用量低于月配额的 10%；
- 相关 IP 没有被列入黑名单；
- 退款申请不能被认定为过度或滥用。

符合条件时，退款会终止相关服务，并删除账户下对应的数据、快照和备份。退款会退回原付款方式，而不是随意换成其他方式。

官方还特别提醒，不要直接通过 PayPal 发起争议来代替正常退款流程。按照条款，PayPal dispute 或 chargeback 可能导致账户服务被暂停，并可能产生处理费用。正确做法是先通过官方退款流程提交申请。

换句话说，PayPal 的争议机制不是搬瓦工退款按钮的替代品。购买前应该确认套餐、机房和计费周期，付款后如果需要退款，优先走服务商的正式申请流程。

160G、320G 和 480G 适合运行更多服务，或者需要较大磁盘、较多流量的项目。升级的主要价值在于容量和资源余量，不代表所有应用都会按比例变快。
